<h1 align="center"><a href="https://typeshade.dev/">TypeShade</a></h1>

<p align="center">
  A TypeScript file that starts with <code>"use typeshade"</code> is a shader.
  TypeShade lowers it to one IR and emits WGSL for WebGPU and GLSL ES 3.00 for WebGL2.
  The host consumes those strings. There is no TypeShade runtime.
</p>
